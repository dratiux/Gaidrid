# Security Policy

## Supported Versions

Only the default branch is supported. Older checkouts and forks are not patched.

## Scope

Gaidrid is a fully offline browser extension: no accounts, no backend, no analytics. See [PRIVACY.md](PRIVACY.md).

In scope: the extension code in this repository (search, shortcuts, weather, sports, RSS, side panel, settings).

Out of scope: third-party services (search engines, Open-Meteo, ESPN, Iconify, favicon service), browser vulnerabilities, and social-engineering attacks.

## Reporting a Vulnerability

Do not open a public issue for security problems. Report privately:

- **GitHub:** [open a private security advisory](https://github.com/dratiux/Gaidrid/security/advisories/new)

Include:

1. A description of the issue and its impact.
2. Reproduction steps or a proof of concept.
3. Affected commit hash, if known.

Do not include personal data (browsing history, queries, locations) in your report. Use a test profile.
